# GitHub Actions AWS CI/CD Pipeline Diagram

This diagram visualizes the workflow of a CI/CD pipeline implemented with GitHub Actions for deploying to AWS. The diagram is generated by the Python script [`src/github_actions_aws_ci_cd.py`](src/github_actions_aws_ci_cd.py), which parses a GitHub Actions workflow YAML file and renders the pipeline structure using Graphviz.

The generated diagram:  
![GitHub Actions AWS CI/CD Pipeline](github_actions_aws_ci_cd.png)

## Components Overview

- **CI Jobs**: Represented as a cluster on the left, CI jobs typically handle tasks such as building, testing, and linting code. Each job and its steps are shown in sequence.
- **CD Jobs**: Shown as a cluster on the right, CD jobs are responsible for deployment and post-deployment actions. Each job and its steps are visualized in order.
- **Job Steps**: Each job contains a series of steps, displayed as nodes connected in execution order.
- **Trigger Link**: The diagram optionally shows a dashed edge from the last CI step to the first CD job, indicating the transition from continuous integration to continuous deployment.

## Key Features

The diagram highlights the following workflow:

1. **CI Cluster**: All jobs related to continuous integration are grouped and visualized with their respective steps.
2. **CD Cluster**: All jobs related to continuous deployment are grouped and visualized with their respective steps.
3. **Transition**: A dashed edge connects the last CI step to the first CD job, representing the trigger for deployment after successful integration.
4. **Footer Note**: The diagram includes a footer credit for the designer.

This visualization helps teams understand the structure and flow of their CI/CD pipeline, making it easier to communicate and review automation processes.
